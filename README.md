# codveda-internship
For the final week of my Full Stack Development Internship at **Codveda Technologies**, I successfully completed and deployed a fully functional, secure **MERN stack application**. 🚀 This project includes 🔐 **JWT-based authentication**, 🛡️ **role-based authorization (Admin/User)**, and robust **route protection** on both frontend and backend. I used **MongoDB** with **Mongoose** for database modeling and validation, while the backend was developed using **Node.js** and **Express.js**, and deployed seamlessly on **Render**. On the frontend side, I built a responsive interface using **React.js**, managed global authentication state using **Context API**, and deployed it professionally via **Vercel**. 💻 The app structure follows a clean **MVC architecture**, implements environment variables for production safety, and showcases real-world deployment practices with full-stack integration. 🌐 This final milestone not only wraps up a meaningful internship journey but also represents a solid, production-ready project that I’m proud to include in my portfolio. ✅✨
